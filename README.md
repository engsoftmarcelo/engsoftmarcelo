## Featured projects

### Drift Invaders: The Pipeline Defense

A Python and Pygame arcade game that teaches introductory MLOps concepts through gameplay.

The project represents production incidents such as data drift, schema breaks, latency spikes, corrupted features, and model decay as in-game threats. It includes automated tests, persistent rankings, accessibility options, modularized logic, and educational documentation.

**Technologies:** Python, Pygame, pytest  
**Concepts:** MLOps education, testing, modularization, persistence, accessibility

[View repository](https://github.com/engsoftmarcelo/drift-invaders-pipeline-defense)
